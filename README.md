# Long4Craft

Long4Craft 主入口网站：独立网站作品展示、六类开发服务、免费源码领取引导与小红书联系入口。

## 本地运行

需要 Node.js 20 或更新版本，以及 Python 3。项目不依赖第三方 JavaScript 包，不需要 API 密钥或安装依赖。

```sh
npm run dev
```

打开终端显示的 `http://127.0.0.1:4326`。停止服务按 Ctrl+C。

## 构建与检查

```sh
npm run check
npm run build
npm run check:seo
```

构建输出为 `dist/`，可部署到支持静态文件的托管服务。Vercel 配置：框架 Other，构建命令 `npm run build`，输出目录 `dist`。正式网站计划使用 `https://long4craft.com`；本地文件不证明网站已经部署。

## 内容维护

- `public/catalog/websites.json`：从工作区公开网站目录复制的版本，只包含已验收项目的公开字段。
- `content/projects.json`：作品展示分类、已核实的源码领取关键词、确知的小红书笔记链接。
- `public/assets/`：真实作品截图、主站生成标志与页面分享图。
- `index.html`：首屏、六类精简服务、底部关于我、FAQ 及联系界面。
- `seo.mjs`：搜索标题、摘要、正式网址、结构化数据与地图生成。
- `SEO.md`：已完成的站内搜索优化与正式上线后的收录验证步骤。
- `public/source-access/`：共用源码入口、原始小红书名片及身份说明。

更新公开目录：

```sh
node scripts/sync-catalog.mjs /absolute/path/to/catalog/websites.json
npm run build
```

新增作品前需要在 `content/projects.json` 添加展示分类和领取关键词，在 `public/assets/` 添加同 slug 的真实网站截图（WebP）。构建时遇到缺失内容将明确报错，避免发布没有截图的卡片。根域名主站记录不会出现在自己的作品列表中。

这是独立源码仓库。不会读取或发布工作区中的项目状态、操作历史、确认记录、本地源码包路径或管理汇总。公开目录的更新需要同步、构建并重新部署；没有隐含的定时更新任务。

## 交互与边界

- 网站卡片打开各项目独立子域名。
- 六类服务的咨询按钮会选中对应分类，可整理并复制需求，再由访客到小红书私信发送。不会在网页上假装提交成功。
- 需求文字只存在当前窗口，关闭咨询窗口清空；不会上传、持久化或自动发送。
- 「获取源码」窗口根据项目显示真实关键词。只有已记录的笔记 URL 才直达笔记，否则打开用户主页并提示查找对应笔记。
- 没有自动评论、自动私信或自动发送源码的功能。
- 公开作品中的预约、会员与购物是概念演示，不代表真实交易服务或客户案例。
- 页头的免费源码入口保留原始二维码，支持悬停、键盘、Escape、手机点按与外部关闭。
- 剪贴板访问失败时展示可手动复制的文字。没有登录、数据库、支付或分析追踪脚本。

## 素材

主站品牌标志由内置 image_gen 生成，提示词见 `ASSET-PROMPTS.md`。作品截图来自 Long4Craft 已上线的四个独立作品，这些作品中的部分视觉由 AI 生成。小红书二维码是用户提供的原图，不由 AI 生成。

使用本源码进行二次创作时，请将域名、作品内容和个人联系方式替换为自己的信息。请勿将原始个人二维码用于其他身份。
